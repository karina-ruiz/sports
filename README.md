# 🛍️ Sports – Tienda deportiva en línea

## 📌 Descripción
**Sports** es una aplicación web creada para una tienda en línea que permite a los usuarios pedir ropa deportiva desde la comodidad de su casa.  
Cuenta con un diseño claro, legible y adaptado para brindar una experiencia de compra cómoda y eficiente.

## ⚡ Funcionalidades
- 🛒 Catálogo de ropa deportiva accesible desde cualquier dispositivo.
- 👕 Interfaz visualmente amigable para el cliente.
- 💳 Proceso de compra rápido y sencillo.
- 🧼 Código limpio y legible para facilitar mantenimiento.

## 🛠️ Tecnologías utilizadas
- Django `5.1.1`
- Pillow `10.4.0`
- Crispy Tailwind `1.0.3`
- IPython `8.27.0`

## ⚙️ Instalación y uso
1. Clona el repositorio:  
   ```bash
   git clone https://github.com/karina-ruiz/sports.git
   ```

2. Ingresa a la carpeta del proyecto:  
   ```bash
   cd sports
   ```

3. Instala las dependencias:  
   ```bash
   pip install -r requirements.txt
   ```

4. Ejecuta el servidor local:  
   ```bash
   python manage.py runserver
   ```

5. Abre tu navegador en `http://localhost:8000` para ver la app.
